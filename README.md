# 闪玩游戏盒

一个使用 Vue 3 + Vite 构建的在线小游戏合集，目前包含 26 款可玩游戏。无需注册和下载，打开网页即可游玩，支持桌面键盘、手机触控和本机成绩保存。

## 本地运行

```bash
npm install
npm run dev
```

本地访问：

```text
http://localhost:5173/xys_con/
```

生产构建与预览：

```bash
npm run build
npm run preview
```

## 设计特点

- 卡通描边、错位阴影和高饱和配色，整体接近轻量网页游戏厅。
- 首页包含搜索、分类、随机开玩、挑战入口和个人高分。
- 每个游戏提供即时反馈、重新开始、暂停或状态提示。
- 所有成绩保存在浏览器 `localStorage`，不会上传到服务器。
- 桌面、平板和手机使用不同布局，移动端提供底部导航和触控操作。
- 手机端游戏卡片改为大图单列，找不同场景纵向全宽展示，按钮与点击区域按触控尺寸优化。
- GitHub Pages 部署包含 SPA 深层路由回退。

## 检查

```bash
npm run check:games
```

浏览器端验收脚本 `final_check.mjs` 会检查首页、排行榜、26 款游戏页面与核心交互，并验证 320/360/390px 视口下的横向溢出、大图卡片和找不同触控布局。
