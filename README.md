# 云视听 · 在线视频 WebApp

基于 **Vue 3 + Vite + Vue Router + Pinia** 从零实现的在线视频应用，UI / 交互对齐腾讯视频：PC 宽屏与移动端（手机、平板）自适应，覆盖首页推荐、频道分类、搜索、播放器、会员中心、观看历史与收藏等完整链路。

## 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 本地开发 http://localhost:5173/xys_con/
npm run build    # 生产构建到 dist/
npm run preview  # 预览构建产物 http://localhost:4173/xys_con/
npm run check:catalog  # 检查片单结构、分集和重复地址
npm run check:sources  # 联网检查全部主源与备用源
```

> Node 版本建议 >= 18。

## 技术栈

| 能力 | 方案 |
| --- | --- |
| 框架 | Vue 3（`<script setup>` 组合式 API） |
| 构建 | Vite 6 |

## 功能清单

### 页面

- **首页**：轮播图（自动播放 / 手势滑动 / 悬停暂停箭头）、快捷分类入口、继续观看（带观看进度条）、频道热播 Tab 切换、猜你喜欢（加载更多）、侧边热播榜与会员卡片
- **频道页**：电视剧 / 电影 / 综艺 / 动漫 / 纪录片 / 少儿，支持类型、地区、排序多维筛选与加载更多
- **搜索页**：搜索联想（影片 / 演员）、搜索历史（单条删除、清空）、热搜榜、搜索发现、关键词高亮结果与综合 / 最新 / 评分排序
- **播放页**：自定义播放器、选集（正序 / 倒序切换）、相关推荐、作品信息、演职员表、评论区（最热 / 最新、点赞、发表评论）
- **会员中心**：多档套餐、会员权益、模拟下单支付（套餐选择 → 支付方式 → 支付成功）
- **观看历史**：带进度记录的剧集卡片、单条删除、清空
- **我的收藏**：收藏影片聚合
- **播放设置**：自动连播、进页自动播放、记住进度、影院模式、默认清晰度 / 倍速 / 音量、弹幕开关 / 透明度 / 字号 / 显示区域
- **404 页面**

### 播放器能力

- 播放 / 暂停、拖拽进度（支持悬停时间预览）、缓冲进度显示
- 音量调节与静音、0.5x ~ 2x 倍速、蓝光 1080P / 超清 720P / 高清 480P / 标清 360P 切换（切换后自动续回原进度）
- 影院模式、网页全屏、自动隐藏控制条
- **弹幕**：滚动弹幕、发送自己的弹幕、开关 / 透明度 / 字号 / 显示区域可调
- **选集切换**、**播完自动连播下一集**、**退出重进自动续播上次进度**
- 多源容错：同名片源的转码版本自动归组；加载 12 秒或缓冲 16 秒无响应会切到备用线路，保留当前进度
- 标题校验：分集名称从真实片源文件生成，卡片封面直接使用对应影片封面，避免剧名与画面错配
- 完整播放：当前收录的公开授权片源不设置试看、会员或付费拦截
- 正版入口：站内未收录的新剧、综艺可在搜索页直达腾讯视频、爱奇艺、优酷与芒果 TV 官方搜索

### 键盘快捷键（播放页）

| 按键 | 功能 |
| --- | --- |
| `空格` / `K` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进 5 秒 |
| `↑` / `↓` | 音量调节 |
| `F` | 全屏切换 |
| `M` | 静音切换 |

### 响应式

- `< 768px`：移动端顶栏（搜索框 + 频道横向 Tab）+ 底部导航栏，播放页沉浸式（隐藏全局导航）
- `768 ~ 1023px`：平板布局，顶栏导航可横向滚动，卡片 3 列
- `>= 1024px`：PC 布局，播放页左侧播放区 + 右侧选集侧栏，卡片 4 ~ 6 列

### 本地持久化

会员状态、收藏、观看历史（剧集 + 进度）、搜索历史、播放设置均写入 `localStorage`（key：`cloud-video-app-state-v1`），刷新后保持。

## 关于视频源（片名 = 实际播放内容）

片单**不是虚构数据**，而是从 **Internet Archive 公有领域影片库（public domain films / serials / cartoons）** 抓取的真实影片，由 `tools/gen-catalog.mjs` 生成到 `src/data/realCatalog.js`：

- **片名即实际内容**：点开《大淘金》播放的就是 Bonanza 剧集本身，不会再出现「片名与画面不符」
- **完整长片 / 完整分集**：电影为 68~119 分钟的完整长片；剧集为完整分集（如《大淘金》20 集 × 49 分钟，全集已上线，全部可看）
- **时长真实**：播放器的时长、进度条、续播位置均来自片源真实时长
- **同源多备份**：同一文件的不同编码互为备用源，单个地址失效会自动切换
- `npm run check:sources` 会对全部有效线路发起 Range 请求，并对 CDN 瞬时 5xx 做三次退避重试

### 想换成自己的片源（例如某部国产剧）

在 `src/data/videos.js` 顶部填写你有权分发的 `CUSTOM_SOURCES`，按视频 id 覆盖即可（一个地址对应一集）：

```js
export const CUSTOM_SOURCES = {
  // 'tv-01': ['https://your-cdn/ep01.mp4', 'https://your-cdn/ep02.mp4']
}
```

id 规则为「频道前缀 + 序号」，如 `tv-01`、`movie-02`、`anime-01`；把对应片目的中文名一起改掉即可。
需要重新抓取或扩充片单时执行 `node tools/gen-catalog.mjs`。生成器会按片名归组同名转码文件，不再按时长把不同分集误合并。

封面图使用 `picsum.photos` 的固定 seed 图片；若网络不可用，`PosterArt.vue` 会自动降级为按影片配色生成的渐变封面，不影响使用。

## 说明

本项目为**技术演示项目**，UI 与交互用于学习参考；会员支付为模拟流程，不产生任何真实交易。

片源均为 Internet Archive 上的公有领域影片，不含受版权保护的内容。国内新剧与综艺通常需要官方账号、授权和带时效的签名流，百度搜索返回的网页索引也不能作为稳定播放地址。

因此站内不会用其他视频冒充《蒸蒸日上》《现在就出发 4》等版权内容；在搜索页查询这些片名会提供正版平台官方入口。若你拥有正版授权地址或官方嵌入播放器，可通过 `CUSTOM_SOURCES` 接入自己的合法片源。
